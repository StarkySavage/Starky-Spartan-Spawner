# AI28 release provenance

This source snapshot corresponds to `Starky-Spartan-Spawner-AI28-Nexus-Update.zip`, prepared on 2026-10-10. Its SHA256 is `c9ce7582828ab48e231ae4d380ba98fcd11afc7bc54c8a1f4483cd6a1bf39d24`.

The release ZIP and installed mod were not changed while preparing this repository. The fresh compiled outputs are review artifacts under ignored `build/`, not replacement release files.

## Native DLL

The bridge is the AI27 native code, with the AI25 alliance fix, AI24 capacity-compatible profile and fault-only diagnostic capture, AI23 Maw routing and earlier spawner changes retained. AI28 only renamed the visible menu label in Lua. The C source/header/assembly in this repository are the build inputs. A fresh assembly object is generated by the build script.

The rebuilt native executable/data sections match the shipped DLL; the `.buildid` section differs. Whole-file reproducibility is not claimed. Exact source and binary hashes and per-section comparisons are recorded in `review/`.

## Controller DLL

The AI28 controller DLL was retained unchanged from the original Ghost7134 Steam distribution. Its accompanying source is included with the original MIT copyright notice. The upstream instructions state Zig 0.16.0 with target `x86_64-windows-msvc`; the exact upstream SDK/runtime environment was not supplied and was not reproduced here.

The verified repository recipe uses `x86_64-windows-gnu`, which builds the provided source without a separate MSVC SDK. It exports the expected controller entry point, but executable sections and the full hash differ from the distributed upstream binary. This is disclosed so reviewers do not mistake a successful rebuild for proof of byte-for-byte equivalence. The upstream build instructions are preserved in `review/UPSTREAM-BUILD.txt` for reference; their descriptions of old gameplay features do not describe the current spawner's enabled feature set.

## Scenario packages and PowerShell

The scenario reproduction script uses stock, hash-checked CU4 inputs from the reviewer's own game. Generated E10/Maw bulk and export chunks match the AI28 public package data. The private bonus-skin adaptation is excluded. `Apply-Capacity-Fix.ps1` is copied exactly from the public AI28 ZIP.

## Known verification limits

- Source build and package checks do not certify malware absence; Nexus must perform its own review.
- Rebuilt DLLs have not been separately gameplay-tested or installed.
- The expanded Marine weapons are not all individually gameplay-tested.
- Join Local Squad Orders inherits mission behavior rather than autonomously hunting.
- The public stock-armor E10 override is structurally tested, but the author's earlier gameplay testing used the personal override.
- Co-op has not been validated.
